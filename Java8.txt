without lambda expression

        System.out.println("Processing ₹" + amount);
    }

Calculator c = (a, b) -> a + b;

Stream API - A stream processes collections in a pipeline.

List<Integer> nums = Arrays.asList(1,2,3,4,5,6);

List<Integer> even = nums.stream()
                         .filter(n -> n % 2 == 0)
                         .toList();

System.out.println(even); // [2, 4, 6]



List<String> names = Arrays.asList("daksh", "rahul");

List<String> upper = names.stream()
                          .map(String::toUpperCase)
                          .toList();

System.out.println(upper); // [DAKSH, RAHUL]




Method Reference - A method reference is a shorthand notation of a lambda expression to call a method.

(n->n.toUpperCase()) can be replaced with String::toUpperCase
(n->System.out.println(n)) can be replaced with System.out::println




optional - A container object which may or may not contain a non-null value. It is used to avoid null checks and NullPointerExceptions.

| Method                     | Meaning                                           |
| -------------------------- | ------------------------------------------------- |
| Optional.of(value)         | Value must NOT be null                            |
| Optional.ofNullable(value) | Value may be null                                 |
| orElse(default)            | Return value if present, otherwise return default |

Optional<String>name=Optional.ofNullable(null);
System.out.println(name.orElse("daksh"));
