Spring MVC - Model View Controller

Browser - Customer places an order (HTTP request).
Tomcat - Waiter receives the order and brings it to the kitchen.
Spring MVC Controller - Chef decides what to do for that URL.
Service / Database - Kitchen prepares the food and fetches data.
HTML / JSON Response - Waiter returns the food to the customer.

Steps to create a MVC

1. Configure the Dispatcher Servlet in web.xml
2. Create the Spring Configuration File
3. Configure the View Resolver
4. Create a Controller
5. Create the View to show page



web.xml


Register DispatcherServlet - Create a servlet whose job is to be Spring MVC's front controller.

<servlet>
    <servlet-name>DispatcherServlet</servlet-name>
    <servlet-class>
        org.springframework.web.servlet.DispatcherServlet
    </servlet-class>
</servlet>


Map URL requests to DispatcherServlet - 

<servlet-mapping>
    <servlet-name>DispatcherServlet</servlet-name>
    <url-pattern>/</url-pattern>
</servlet-mapping>



DispatcherServlet-servlet.xml

<?xml version="1.0" encoding="UTF-8"?>

<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:context="http://www.springframework.org/schema/context"

           https://www.springframework.org/schema/context/spring-context.xsd

           https://www.springframework.org/schema/mvc/spring-mvc.xsd">

    <context:component-scan base-package="com.daksh.controller"/>

    <mvc:annotation-driven/>
    <bean class="org.springframework.web.servlet.view.InternalResourceViewResolver">
        <property name="prefix" value="/"/>
        <property name="suffix" value=".jsp"/>
    </bean>
</beans>

package com.daksh.controller;

import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.ResponseBody;
import org.springframework.web.servlet.ModelAndView;

import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;
@Controller
public class CalculationController {
	
	@RequestMapping("/div")
    public ModelAndView div(HttpServletRequest req, HttpServletResponse res) {
        int a=Integer.parseInt(req.getParameter("t1"));
        int b=Integer.parseInt(req.getParameter("t2"));
        int k=a/b;
        ModelAndView mv=new ModelAndView();
        mv.setViewName("calculator");
        mv.addObject("result",k);
        return mv;
    }
	
	@RequestMapping("/mul")
    public ModelAndView mul(HttpServletRequest req, HttpServletResponse res) {
        int a=Integer.parseInt(req.getParameter("t1"));
        int b=Integer.parseInt(req.getParameter("t2"));
        int k=a*b;
        ModelAndView mv=new ModelAndView();
        mv.setViewName("calculator");
        mv.addObject("result",k);
        return mv;
    }
    
    
    @RequestMapping("/add")
    public ModelAndView add(HttpServletRequest req, HttpServletResponse res) {
        int a=Integer.parseInt(req.getParameter("t1"));
        int b=Integer.parseInt(req.getParameter("t2"));
        int k=a+b;
        ModelAndView mv=new ModelAndView();
        mv.setViewName("calculator");
        mv.addObject("result",k);
        return mv;
    }
    
    
	@RequestMapping("/sub")
    public ModelAndView sub(HttpServletRequest req, HttpServletResponse res) {
        int a=Integer.parseInt(req.getParameter("t1"));
        int b=Integer.parseInt(req.getParameter("t2"));
        int k=a-b;
        ModelAndView mv=new ModelAndView();
        mv.setViewName("calculator");
        mv.addObject("result",k);
        return mv;
    }
}








Before going further:

| HTML                                | JSP                          |
| ----------------------------------- | ---------------------------- |
| Static page                         | Dynamic page                 |
| Browser reads it directly           | Server processes it first    |
| Can't directly use Java/Spring data | Can display server-side data |
| `.html`                             | `.jsp`                       |
| No server-side processing           | Server-side processing       |


Monolithic - Everything is packaged and deployed together. If you change one part, you generally build/deploy the application as a whole.
MONOLITH

        ONE APPLICATION
 ┌─────────────────────────┐
 │ Login │ Orders │ Payment│
 │ Users │ Product│ etc.   │
 └─────────────────────────┘


Microservices - Now you can update/deploy the Order service without necessarily redeploying Login or Payment.
┌─────────┐  ┌─────────┐  ┌─────────┐
│ Login   │  │ Orders  │  │ Payment │
│ Service │  │ Service │  │ Service │
└─────────┘  └─────────┘  └─────────┘
