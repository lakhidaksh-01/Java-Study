Spring Boot starters are Dependency Descriptors 
(Dependency= External Libraries or JARs  , Descriptor= configuration specifying Jarsand their versions)

Spring Boot starters combine all the necessary libraries (JAR files) for a particular feature or technology into a single dependency.

examples

1. spring-boot-starter → Core Spring Boot starter providing basic auto-configuration, logging, and core Spring Boot functionality.
2. spring-boot-starter-web → Used to build web applications and REST APIs using Spring MVC, embedded Tomcat, and JSON support.
3. spring-boot-starter-data-jpa → Provides JPA/Hibernate support for working with relational databases using repositories and ORM.
4. spring-boot-starter-security → Adds Spring Security for authentication, authorization, password protection, and securing web applications/APIs.
5. spring-boot-starter-thymeleaf → Integrates Thymeleaf for creating dynamic server-side HTML pages.
6. spring-boot-starter-aop → Provides Aspect-Oriented Programming support for features like logging, transactions, and method interception.
7. spring-boot-starter-test → Provides testing libraries such as JUnit, Mockito, Spring Test, and AssertJ for unit and integration testing.
8. spring-boot-starter-actuator → Provides production-ready monitoring and management endpoints such as health, metrics, info, and application status.

@SpringBootApplication -> Main annotation provides setup and configurations for our spring boot application.

@SpringBootApplication = @Configuration (Tells Spring this class contains bean/configuration definitions.) 
                             + 
                         @ComponentScan (Tells Spring to search packages for classes like @Component, @Service, @Controller, etc.)
                             + 
                         @EnableAutoConfiguration (Tells Spring Boot to automatically configure things based on your dependencies and environment.)




there is always a fomate we have to follow for backend structure of spring boot application

1. Controllers - Handle incoming https requests, process them and return appropriate responses.
2. services - contains business logic functions which are triggered by controllers.
3. domain - conatins entities(tables) and there enums.
4. dto - the format of incomming and outgoing data.
5. repositories - jpa repositories which are used to interact with database. and also has predefined methods for CRUD operations.
