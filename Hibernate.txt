Hibernate is used to automate database persistence by mapping Java objects to relational database tables, reducing manual JDBC and SQL code.

Hibernate is a Java framework that implements ORM.


What is ORM?

Object-Relational Mapping - the technique of Mapping Java objects to database tables.


why we use Hibernate?

- Eliminates the need for manual JDBC and SQL code.
- Automatic transaction management.
- portability across different databases.
- Reduces SQL dependency with HQL (Hibernate Query Language).


JDBC vs JPA vs Hibernate

JDBC (Java Database Connectivity) - Direct database interaction using SQL.
JPA (Jakarta Persistence API) is a specification/standard for ORM in Java.
Hibernate is a popular framework that implements the JPA specification with adavance features.

example : Imagine cars.
JPA = the driving rules / standard
Hibernate = a specific car that follows those rules



Core Components of Hibernate:

SessionFactory: Responsible for creating Session objects.
Session: Represents a conversation between the application and the database.(short-lived object)
Transaction: Manages commit and rollback of database operations.
Query & Criteria API: Used to execute HQL (Hibernate Query Language) or native SQL queries.
Hibernate Configuration File: Used to configure Hibernate settings and database connection properties.(hibernate.cfg.xml)


Steps to use Hibernate:
1. Load Hibernate Configuration File (hibernate.cfg.xml).
2. Create SessionFactory from Configuration.
3. Open a Session from SessionFactory.
4. Begin a Transaction.
5. Perform CRUD operations (Create, Read, Update, Delete).
6. Commit the Transaction.
7. Close the Session and SessionFactory.

        <property name="hibernate.show_sql">true</property>
		<property name="hibernate.format_sql">true</property>
        <property name="hibernate.hbm2ddl.auto">update</property>

        <!-- Add your annotated entity classes here -->
        <mapping class="com.daksh.hibernate_demo.entities.Student"/>

    </session-factory>
</hibernate-configuration>




hibernate.dialect	Tells Hibernate which database you're using (MySQL in your case), so it generates compatible SQL.
hibernate.show_sql	true → Displays SQL queries in the console.
hibernate.format_sql	true → Makes SQL queries easier to read by formatting them.
hibernate.hbm2ddl.auto	update → Automatically updates the database table structure based on your Java entity classes.

package com.daksh.hibernate_demo.entities;

import jakarta.persistence.Entity;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;
import jakarta.persistence.Table;
import jakarta.persistence.Column;
import jakarta.persistence.Lob;
@Entity
@Table(name="students")
public class Student {
	
	@Id
	@GeneratedValue(strategy=GenerationType.IDENTITY)
	
	private int id;
	@Column(name="name", length=100, unique=true)
	private String name;
	
	@Column(name="city", length=100, nullable=true)
	private String city;
	
	@Lob
	private String review;

	public int getId() {
		return id;
	}

	public void setId(int id) {
		this.id = id;
	}

	public String getName() {
		return name;
	}

	public void setName(String name) {
		this.name = name;
	}

	public String getCity() {
		return city;
	}

	public void setCity(String city) {
		this.city = city;
	}

	public String getReview() {
		return review;
	}

	public void setReview(String review) {
		this.review = review;
	}
	
}

package com.daksh.hibernate_demo.util;
import org.hibernate.SessionFactory;
import org.hibernate.cfg.Configuration;
public class Sessionbuilder {
	private static SessionFactory sessionFactory;

    static {
        try {
            // Create the SessionFactory from hibernate.cfg.xml
            sessionFactory = new Configuration().configure("hibernate.cfg.xml").buildSessionFactory();
        } catch (Throwable ex) {
            throw new ExceptionInInitializerError(ex);
        }
    }

    public static SessionFactory getSessionFactory() {
        return sessionFactory;
    }
}

package com.daksh.hibernate_demo;

import org.hibernate.*;
import com.daksh.hibernate_demo.util.*;
import com.daksh.hibernate_demo.entities.*;
public class Studentservice {
	static SessionFactory sessionfactory = Sessionbuilder.getSessionFactory();
	static void insert(Student s1) {
		try(Session session=sessionfactory.openSession()){
			Transaction transaction=session.beginTransaction();
        	session.persist(s1);
        	transaction.commit();
		}catch(Exception e) {
			e.printStackTrace();
		}
	}
	static void update(int id,Student s1) {
		try(Session session =sessionfactory.openSession()){
			Transaction transaction=session.beginTransaction();
			Student currstudent=session.get(Student.class,id);
			if(currstudent!=null) {
				currstudent.setCity(s1.getCity());
			}
			transaction.commit();
		}catch(Exception e) {
			e.printStackTrace();
		}
	}
	static void view(int id) {
		try(Session session=sessionfactory.openSession()){
			Student currstudent=session.get(Student.class,id);
			if (currstudent != null) {
	            System.out.println("Name   : " + currstudent.getName());
	            System.out.println("City   : " + currstudent.getCity());
	            System.out.println("Review : " + currstudent.getReview());
	        } else {
	            System.out.println("Student not found with id: " + id);
	        }
		}catch(Exception e) {
			e.printStackTrace();
		}
	}
	static void delete(int id) {
		try(Session session=sessionfactory.openSession()){
			Transaction transaction=session.beginTransaction();
			Student currstudent=session.get(Student.class,id);
			if (currstudent != null) {
	            session.remove(currstudent);
	        }
			transaction.commit();
		}catch(Exception e) {
			e.printStackTrace();
		}
	}
}

	static void viewall() {
		try(Session session=sessionfactory.openSession()){
			Transaction transaction=session.beginTransaction();
			String hql="FROM Student";
			List<Student>list=session.createQuery(hql,Student.class).getResultList();
			if (list.isEmpty()) {
	            System.out.println("No students found.");
	        } else {
	            list.forEach(s -> {
	                System.out.println("-------------------");
	                System.out.println("ID     : " + s.getId());
	                System.out.println("Name   : " + s.getName());
	                System.out.println("City   : " + s.getCity());
	                System.out.println("Review : " + s.getReview());
	                System.out.println("-------------------");
	            });
	        }
			transaction.commit();
		}catch(Exception e) {
			e.printStackTrace();
		}
	}
	static void viewallbycity(String city) {
		try(Session session=sessionfactory.openSession()){
			Transaction transaction=session.beginTransaction();
			String hql="FROM Student WHERE city = :city";

	            System.out.println("No students found.");

fetch and cascade types

cascade types - if i delete student the all certificates of that student will also be deleted automatically. CascadeType.ALL

fetch types - if i fetch student the all certificates of that student will also be fetched automatically or later.
FetchType.EAGER - fetch all certificates of that student automatically.
FetchType.LAZY - fetch all certificates of that student later when we call it.
