Exception Handling
- checked exceptions: These are exceptions that are checked at compile time. External system problems. Examples include IOException, SQLException, etc.
- unchecked exceptions: These are exceptions that are not checked at compile time. They occur due to programming errors. Examples include NullPointerException, ArrayIndexOutOfBoundsException, ArithmeticException.

 Example  int a = 10 / 0; // ArithmeticException

 Why companies use it

* Prevent application crashes
* Show proper error messages
* Keep APIs and services running
* Clean up resources safely


# 1. try, catch, finally

 Syntax

try {
    int a = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Cannot divide by zero");
} finally {
    System.out.println("Cleanup code");
}


Meaning

| Block     | Purpose           |
| --------- | ----------------- |
| try       | Risky code        |
| catch     | Handle exception  |
| finally   | always executes/ can use instead of catch |
| throw     | Manually throw exception and declare |
| throws    | maybe can throw exception |



## Important points

* Multiple catch blocks are allowed.
* `finally` usually executes even when an exception occurs.

import java.util.*;
class Main {
    static void registerUser(int age) throws Exception{
        if(age<18){
            throw new Exception("below 18");
        }else{
            System.out.println("Registered");
        }
    }
    public static void main(String[] args) {
        Scanner sc=new Scanner(System.in);
        int age=sc.nextInt();
        try{
            registerUser(age);
        }catch(Exception e){
            System.out.println(e.getMessage());
        }
    }
}
