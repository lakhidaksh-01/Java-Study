# Strings in java

Java makes String immutable to improve security, memory efficiency, performance, and thread safety.

String str="Daksh";
String str2=new String(" Lakhi");
String str3=str.concat(str2); // Daksh Lakhi

1. str.length() // 5
2. str.charAt(1) // a
3. str.substring(1,4) // aks
4. str.indexOf('k') // 3
5. str.toLowerCase() // daksh
6. str.toUpperCase() // DAKSH
7. str.equals("Daksh") // true
8. str.equalsIgnoreCase("daksh") // true
9. str.replace('a','o') // Doksh
10. str.trim() // removes leading and trailing spaces
11. str.lastIndexOf('k') // 3
12. String[] words=str.split(" ");
13. String.join(" ",words) // Daksh


StringBuffer and StringBuilder are mutable classes that allow you to modify strings without creating new objects. StringBuffer is synchronized, making it thread-safe, while StringBuilder is faster but not thread-safe.

StringBuffer sb=new StringBuffer("Daksh");
sb.append(" Lakhi"); // Daksh Lakhi
sb.insert(5," Lakhi"); // Daksh Lakhi Lakhi
sb.delete(5,11); // Daksh Lakhi
sb.reverse(); // ihkaL hskaD
