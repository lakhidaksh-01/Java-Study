Multithreading = executing multiple tasks (threads) at the same time within a program.

Imagine your company’s backend server receives 1,000 API requests at the same time.
If Java handled them one by one, users would wait forever.
So Java creates multiple threads to work simultaneously.


Real company example

User A → Login API
User B → View Products API
User C → Payment API
User D → Chat Message API

Each request is usually processed by a separate thread.

One line definition: A thread is the smallest unit of execution inside a Java program.




There are two ways to Multithreading


1. extends Thread class (built-in class to create a thread)

class MyThread extends Thread {
    public void run() {
        System.out.println("Task running in: " + Thread.currentThread().getName());
    }
}

public class Main {
    public static void main(String[] args) {
        MyThread t1 = new MyThread();
        t1.start(); // creates new thread
        t1.run(); // runs in main thread
    }
}
